Sistem Pengelompokan Destinasi Wisata

Tentang Proyek

Projek ini merupakan sistem rekomendasi destinasi wisata di Yogyakarta yang dikembangkan untuk membantu pengguna menemukan tempat wisata berdasarkan karakteristik dan kriteria tertentu. Sistem memanfaatkan metode K-Means Clustering untuk mengelompokkan destinasi wisata berdasarkan data yang telah ditentukan, sehingga dapat menghasilkan kelompok destinasi dengan karakteristik yang serupa.

Metode K-Means digunakan untuk melakukan proses clustering terhadap data destinasi wisata, seperti harga tiket, lokasi, fasilitas, rating, dan karakteristik wisata. Hasil pengelompokan kemudian digunakan sebagai dasar dalam memberikan rekomendasi destinasi kepada pengguna. Sistem dikembangkan menggunakan framework Laravel sebagai backend dan pengelolaan proses aplikasi. Data destinasi dan hasil clustering disimpan dalam database sehingga dapat dikelola dan ditampilkan melalui antarmuka website.

Tentang Proyek

Projek ini merupakan aplikasi e-commerce berbasis web yang dikembangkan untuk memudahkan proses penjualan dan pembelian pakaian pria secara online. Projek ini dibangun menggunakan konsep full-stack web development, di mana sisi frontend digunakan untuk menampilkan antarmuka yang responsif dan interaktif, sedangkan sisi backend digunakan untuk mengelola database, autentikasi pengguna, produk, transaksi, dan proses bisnis aplikasi.

JavaScript — digunakan untuk memberikan interaksi dinamis pada halaman, seperti pengelolaan keranjang, validasi form, dan interaksi pengguna.
MySQL— digunakan sebagai database untuk menyimpan data pengguna, produk, kategori, pesanan, dan transaksi.
Projek ini dibuat untuk menerapkan konsep full-stack development, mulai dari perancangan database, pengembangan backend, pembuatan antarmuka frontend, hingga integrasi antara frontend, backend, dan database dalam sebuah sistem e-commerce yang terintegrasi.
